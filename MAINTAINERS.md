# Maintainer credit and public contact

No maintainer profile has yet been supplied for publication.

Maintainers choose the identity and contact details they publish. An alias is
welcome; a legal name, personal email, location, employer, or personal account
is not required. Publish only the exact fields the person intentionally provides
for public use. Do not infer consent from local Git configuration, an SSH login,
private steering, or a previously visible document.

Optional profile fields: chosen display name or alias, project role, approved
public contact, and approved public profile URL. Omit all unselected fields.
Do not include home addresses, private phone numbers, credentials, private
infrastructure, or information unrelated to project credit/support.

Keep consent/source records privately. Ask the maintainer before changing the
public fields. Check Git author metadata independently: a sanitized README
does not hide a personal address in commits. A GitHub-provided private/noreply
commit address or chosen public address can be selected when setting up the
account.

Required existing license notices and public source citations are preserved.
The privacy audit can allow an explicitly approved identity only in this file
with its --public-identity option; it must still report that contact elsewhere.
